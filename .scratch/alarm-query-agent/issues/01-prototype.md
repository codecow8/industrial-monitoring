# 01：历史告警 Agent 原型

Status: resolved

Blocked by: none

## 设计范围

使用 baoyu-design 原地扩展 `industrial-editor.html` 与 `prototype.jsx`，保持现有帮助侧栏样式，不创建版本副本。

- 显示当前页面、当前发布版本和只读范围，提供“查询当前页面历史告警”示例问题。
- 未发布时提示先手动发布；助手没有发布操作按钮。
- 固定模拟 21 条完整触发/恢复记录，首批 20 条，显示总数与实际时间窗；“继续查看”追加到 21 条，截止时间不变。
- 每条展开显示触发、恢复的前后观测值、时间及 ID；明确所有 ID 为模拟数据，不推断根因。
- 发布版本变化后，旧结果只供查看，旧分页禁用，提供显式重新查询当前版本。
- 无记录说明完整记录的范围限制，不推断没有活动告警；失败不返回空结果，重试不重复插入问题。
- 原型底部历史案例下拉框仅用于评审，不进入正式业务 UI。

## 轻量验证

未发布前提、20→21 分页、固定截止时间、观测展开、版本变化禁用分页、空结果语义、失败及重试去重检查通过，无控制台错误。不做全量回归，不调用真实模型或 API。

## 评审路径

先点击顶部“发布版本”，再打开“使用帮助”并点击历史查询示例。可展开观测依据、在列表末尾继续查看；底部下拉框可切换无记录和失败案例，再输入“查询历史告警”。再次发布可检查旧版本提示。
