# 04：Vue 历史告警接入

Status: resolved

Blocked by: none

## 实现

- 按批准原型显示当前页面/版本、历史范围和总数、已恢复记录、观测值及编号、无记录及版本变化。
- 创建会话时绑定路由页面；切页清空会话，旧请求的迟到结果不能写入新页。编辑器切页同步加载正确 Schema，加载顺序防止旧请求覆盖新页。
- 分页按钮携带显式 next 动作与查询 ID，由服务端控制，不让模型重猜游标；旧查询各保留自己的固定截止时间，不能选择其他会话的查询。
- 每批最多 20 条，客户端合并同一查询的 20+1 数据，拒绝混版本/范围/重复记录；重试沿用原编号，不重复问题。
- 正式 UI 没有模拟下拉框或控件，记录取自真实接口；时间标注服务端接收时间、本机时区，长 ID 可以换行查看。
- 当前仍为本机 Web；Electron 只验证构建，不扩展个人 Pi 登录权限或 null 来源。
