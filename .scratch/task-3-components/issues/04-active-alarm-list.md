# 04: 活动告警列表组件闭环

**What to build:** 组态工程师可以添加并配置一个告警列表组件，发布后现场操作员能查看当前页面仍未恢复的阈值越界与设备故障，并识别告警数据是否已经过期。

**Blocked by:** 03: 设备状态组件闭环.

**Status:** resolved

- [x] 组件栏解锁告警列表，点击添加一个 `alarm-list`，已存在时再次点击只选中它
- [x] 属性面板只配置组件标题，默认标题为“活动告警”
- [x] 数值达到组件阈值或 Device State 等于 `2` 时产生 Active Alarm，收到明确恢复值后移除
- [x] 相同 `dataKey`、告警类型和阈值或状态码只显示一条，设备故障排在阈值越界之前
- [x] Data Freshness 过期时保留最后 Active Alarm，并标记数据已过期
- [x] 等待数据和当前无活动告警使用不同空状态
- [x] 第一版只读，不包含确认、删除、筛选、历史查询或后端告警持久化
- [x] 原型通过用户评审后，再确认 TDD seams 并修改 Vue
