# 01: 实时趋势图闭环

**What to build:** 组态工程师可以从组件栏添加并配置单数据键趋势图，发布后现场操作员可以在运行态查看当前会话最近 60 秒的 Trend Sample，并识别阈值越界、数据过期与断流缺口。

**Blocked by:** None (Task 2-03 实时遥测闭环已完成).

**Status:** resolved

- [x] 组件栏解锁折线图，点击可添加一个默认 `trend-chart`，并可选中、拖动、缩放和编辑标题、`dataKey`、单位、小数位与告警阈值
- [x] PageSchema 保持 `version: "1.0.0"` 并兼容旧的纯指标卡页面
- [x] 运行态对每个 `dataKey` 每秒记录该秒最新值，只保留当前会话最近 60 个 Trend Sample
- [x] 趋势图 X 轴显示实际时间，Y 轴自动量程包含告警阈值，越界线段和点使用告警色
- [x] 等待数据时显示空态；5 秒未更新时保留旧趋势并标记过期；断流期间不复制旧值，恢复后曲线保留缺口
- [x] 自动化测试证明 Schema 兼容、每秒采样、60 点裁剪、断流缺口、阈值告警和编辑到运行态闭环
