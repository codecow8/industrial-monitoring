# 02: 组件右键菜单与删除

**What to build:** 组态工程师在编辑画布右键组件时看到自定义菜单，可以删除被右键的组件，并能通过现有撤销功能恢复。

**Blocked by:** 01: 实时趋势图闭环.

**Status:** resolved

- [x] 编辑画布上的右键操作不再显示浏览器默认菜单
- [x] 右键组件时选中该组件，并在指针附近显示自定义菜单
- [x] “删除组件”同步更新画布、PageSchema 和当前选中状态
- [x] 删除操作进入现有历史，点击撤销可恢复组件
- [x] 点击菜单外部或右键画布空白处会关闭菜单
