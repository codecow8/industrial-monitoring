# 03: 设备状态组件闭环

**What to build:** 组态工程师可以添加并配置设备状态组件，发布后现场操作员能区分设备的停止、运行、故障、维护、未知和数据过期状态。

**Blocked by:** 01: 实时趋势图闭环; 02: 组件右键菜单与删除.

**Status:** resolved

- [x] 组件栏解锁设备状态，点击添加一个 `device-state`，已存在时再次点击只选中它
- [x] 属性面板可配置设备名称、组件标题和独立 `dataKey`，默认为 `pump1.operating_state`
- [x] 状态码 `0/1/2/3` 分别显示停止、运行、故障、维护，其他值显示未知状态和原始状态码
- [x] 等待数据时显示等待态；Data Freshness 过期时保留最后 Device State，但降低强调并显示过期时间
- [x] 模拟器通过现有遥测通道循环发送运行、维护、运行、故障、停止、运行
- [x] 自动化测试证明 Schema 兼容、编辑发布闭环和 Device State/Data Freshness 的可见状态
