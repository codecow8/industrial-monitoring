# 02：活动告警查询原型

Status: resolved

## 已完成

使用 baoyu-design 在现有 `industrial-editor.html`、`prototype.jsx` 原地增加活动告警查询，不创建原型副本。

- 编辑器“使用帮助”中增加活动告警查询建议问题，沿用现有侧栏。
- 概要展示查询时间、服务器 5 秒新鲜度、页面版本、总数、显示条数与资料覆盖。
- 展开告警可查看最后观测值、接收时间、观测 ID、条件及版本，不提供起点或根因结论。
- 每次重新查询更新模拟快照；未发布与发布版本变化明确提示。
- 原型底部“活动案例”可切换新鲜告警、过期保留、部分缺数、无数据、正常、未配置、23 条显示 20 条和失败。
- 失败保留旧资料并明确没有新结果，可重试；原型内容始终标注为模拟案例。
