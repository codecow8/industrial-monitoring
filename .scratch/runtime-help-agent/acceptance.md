## 本轮完成

- 运行态页面与编辑器页面均先校验登录，未登录回登录页并保留目标路径；登录后返回目标运行页。
- 运行态没有退出登录按钮，编辑器保留；运行态复用现有帮助侧栏与只读工具。
- 绑定页面与已加载发布版本。同页同版本跨入口保留会话；换页、显式换版本、退出登录或刷新重置。
- 新版通知使旧帮助对话只读，停止发送/重查/历史继续，并丢弃在途回复。没有物理取消服务器模型任务的新增协议。
- 查询返回页面或版本不符，即使 WS 没有通知，也拒绝结果；旧快照保持，运行态查询暂停。
- 页面切换/卸载使旧版加载和会话回复失效，避免旧加载覆盖新上下文。
- 操作指南与 README 更新为已登录入口、运行态无退出、会话及版本暂停规则。
