# 03：按用户问题检索指南章节

Status: resolved

Blocked by: none

## 目标与公开接口

上一切片已经把指南读取为章节数组。本切片通过 `searchGuide(sections, query)` 返回相关章节及排序分数，用于后续 Pi 自定义工具。

`GuideSearchResult` 包含原章节的 `title`、`content` 和 `score`。返回最多三个正分章节；空问题或没有匹配时返回空数组。标题和原文保留，供后续回答引用。

## 实现边界

- 使用 Node 内置中文分词与本地词项匹配，不安装分词或数据库依赖。
- 过滤常见问句词和中文单字；标题匹配比正文匹配权重高。
- 每个问题词最多贡献一次匹配，避免重复输入和长章节中的重复文案虚增分数。
- 分数仅用于候选章节排序，不代表正确率、置信度或充分证据。
- 本切片不调用模型、不创建 HTTP 服务、不修改界面。

## 验收

- [x] 发布问题能召回对应的操作原文。
- [x] 数据键问题优先返回绑定数据章节。
- [x] 组件数量问题能召回实际数量限制。
- [x] 空问题、纯标点、无资料关键词返回空数组。
- [x] 支持大小写不敏感的英文数据键匹配。
- [x] 结果有上限，不修改输入章节。

测试只通过公开接口检验排序、原文及无匹配行为，不依赖内部词表或具体分数公式。

## 已知边界

关键词匹配不能理解同义词或连续追问中的省略。无匹配可以返回空结果，但命中“设备”“配置”等通用词的未覆盖问题也可能返回候选章节，不能把候选章节当作充分依据。后续 Pi 工具应允许模型改写检索词，并要求回答引用原文、资料不足时明确说明。
