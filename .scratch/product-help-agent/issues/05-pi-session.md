# 05：Pi 内存会话与终端问答

Status: resolved

Blocked by: none

## 本切片

创建 `createHelpSession()`，读取固定产品指南，复用本机 Pi 登录与模型偏好。终端通过 `npm run dev --prefix services/agent` 提问；同一进程连续追问，重新启动清空。本切片不接 HTTP、不改 UI。

## 调用流程与权限

1. `session.ts` 加载指南，创建 `search_product_guide` 工具。
2. 拷贝 Pi 的模型偏好到内存设置，不写用户设置文件。
3. 使用空 `ResourceLoader`，禁止加载扩展、技能、提示模板和 AGENTS.md；工具白名单仅含指南检索。
4. 使用 `SessionManager.inMemory`；`session.prompt` 完成本轮工具调用与回答后再接收追问。
5. 提示词要求根据实际检索资料作答、引用章节、资料不足时说明，不声称执行业务操作。
6. `cli.ts` 沿用环境代理，退出时释放会话与网络连接。

## 已知边界

- SDK 锁定的间接依赖 `brace-expansion` 仍有 1 项 high 安全告警，尚未消除，服务化前需处理。
- 资料引用与拒绝编造目前依赖提示词，真实模型冒烟不代表对所有问题都有保证。
- 模型上下文超长处理、并发请求与 HTTP 会话生命周期不是本切片范围。
