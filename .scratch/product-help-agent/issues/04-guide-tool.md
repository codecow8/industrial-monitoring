# 04：封装 Pi 只读指南工具

Status: resolved

Blocked by: none

## 目标与接口

通过 `createGuideSearchTool(sections)` 返回符合 Pi SDK `ToolDefinition` 的工具，名称为 `search_product_guide`。本切片不调用模型、不建立 HTTP 服务、不修改 UI。

## 实现与学习要点

- `parameters` 是模型可见的参数 Schema。只允许非空、最多 500 字符的检索词 `query`，参数校验由 Pi 在执行工具前完成。
- 章节通过闭包传入，不允许模型传文件路径；`execute` 只调用已有的 `searchGuide`。
- 模型读取 `content` 中的 JSON；调用方通过 `details` 获得同一份结构化结果。
- 候选资料包含固定来源路径、标题和原文，不包含检索分数。
- `found` 只代表命中候选章节，不保证充分依据；无匹配返回 `not_found` 和空资料，提示不能编造。
- 按用户要求固定 Pi SDK 官方稳定最新版 `1.0.0`（2026-10-02 核对），TypeBox 对齐 `1.3.27`，通过其真实 TypeScript 类型检查接口兼容性。新服务独立 npm 锁文件，不改根 workspace 或全局 Pi。
