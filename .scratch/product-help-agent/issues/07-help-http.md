# 07：产品帮助 HTTP 接口

Status: resolved

Blocked by: none

## 已确认决策

- 首版只供本机开发与演示，监听 loopback，不向局域网或公网开放。
- 复用本机 Pi 登录和模型配置，不在项目中写入凭据，不提供多人共享个人登录的能力。
- 一轮问答完成后返回完整回答及来源，不做流式传输。
- 本切片先实现并验证 HTTP 接口，Vue 接入在下一切片完成。
- 已批准原型决定：关闭侧栏保留当前对话，刷新后新会话；失败重试不重复插入用户问题。

## 生命周期决策（已确认）

- 每个标签页独立会话，关闭保留，刷新新建；服务闲置 15 分钟清理，过期返回 410。
- 单会话串行，60 秒超时；相同请求编号去重，成功缓存；关闭侧栏不取消生成。
- 超时发出终止信号，SDK 结算前不放行新生成。失败回退到请求前上下文，晚到结果不缓存。

## 前置安全工作

通过本服务独立 pnpm workspace 将 `brace-expansion` 固定为 `5.0.12`；实际依赖树、冻结安装及完整审计通过，未发现已知漏洞。移除生成的 npm 锁文件，不改根目录依赖或全局 Pi。

仅监听 127.0.0.1:8001，限制 Host、Origin、客户端自定义头、JSON 参数和请求体。最多 20 会话，每会话最多 100 个请求编号。本地安全边界不等于企业多人鉴权，不允许对外开放或放开 null 来源。

## 接口与验证

- `POST /api/help/sessions` 创建会话；`POST /api/help/sessions/<id>/questions` 返回完整回答及真实来源。
- 启动：`pnpm --dir services/agent dev:http`。
- 22 项离线测试及类型检查通过，覆盖隔离、去重、并发、闲置过期、失败重试、超时、晚到结果、请求限制和来源校验。
- 本机真实模型完成发布及连续追问两轮 HTTP 问答；对应来源正确，同编号取回一致缓存。
- Vue 尚未接入，不视为全部真实模型、浏览器或 Electron 验收通过。
