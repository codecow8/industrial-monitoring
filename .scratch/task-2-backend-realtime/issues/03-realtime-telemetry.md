# 03: 实时遥测闭环

**What to build:** 设备模拟器持续产生冷却泵温度数据，经后端实时通道推送到运行态；指标卡根据 `dataKey` 显示最新值，并在连接中断和恢复时给现场操作员清楚的状态反馈。

**Blocked by:** 02: 发布版本闭环.

**Status:** resolved

- [x] 指标卡无需刷新页面即可显示最新数值，并继续遵守小数位与告警阈值配置
- [x] 多条快速更新在同一渲染帧合并，不要求每条消息直接重渲染组件
- [x] 连接断开时页面显示离线状态，服务恢复后可以自动重新连接
