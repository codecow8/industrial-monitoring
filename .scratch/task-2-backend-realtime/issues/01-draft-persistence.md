# 01: 草稿持久化闭环

**What to build:** 组态工程师保存页面草稿后，系统通过后端校验并持久化 PageSchema；重新打开或刷新编辑器时，可以从后端恢复同一份草稿，而不是依赖当前浏览器的本地存储。

**Blocked by:** None (can start immediately).

**Status:** resolved

- [x] 保存草稿通过公开的后端接口完成，合法 PageSchema 返回成功结果
- [x] 重新加载编辑器后，设备名称、指标标题、位置和尺寸与最近一次保存一致
- [x] 不符合 PageSchema 合同的数据返回可理解的校验错误，且不会覆盖已有草稿
- [x] PostgreSQL 重启后，已保存草稿仍能通过同一个公开接口读取
- [x] 后端接口测试和浏览器保存—刷新测试在实现前可失败、实现后通过
