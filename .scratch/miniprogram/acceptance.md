- 没有上传、预览二维码或部署生产。
- 没有微信真机、生产 HTTPS/WSS、后台长时间挂起的设备验收。
- 没有调用真实模型；分析接口既有 mocked API 验证与客户端版本合同通过，实际模型结论与原生成功/失败显示需要后续验收。
