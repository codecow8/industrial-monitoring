# 账号密码登录

Status: resolved

原型已由用户明确批准（2026-10-03），密码显示/隐藏使用眼睛图标。

- Vue 登录页、访问保护、退出、401 后重新登录并返回原目标。
- FastAPI 账号密码校验；scrypt 密码哈希、数据库会话、HttpOnly / SameSite Cookie。
- 无注册、角色管理、密码找回；账号由 CLI 创建。
- 验证真实 HTTP 登录、错误密码、退出、过期、请求来源检查和登录尝试限速。
- 当前运行态、编辑、发布和智能分析均需要登录；运行态不显示退出登录按钮。

## 后续策略更正
