# 02：运行态新鲜度与版本变化原型

Status: resolved

## 内容

使用 baoyu-design 原地更新既有工业监控原型，保留单一设计资产。

- 每个数据键独立展示观测年龄；部分缺数、正常值过期和无数据不显示“所有条件正常”。
- 过期告警保留并提示需核实；模拟断线重连后不自动生成新值或重置原年龄。
- “新鲜度原型案例”可切换缺数、过期正常、旧快照告警、单键更新、无数据等情况。
- 模拟电脑时间快 5 分钟时，原型中的服务器观测年龄不变为新鲜。
- 模拟发布新版后保留旧画面、旧版本及最后值，禁用继续更新和旧版本业务查询，并提示手动刷新。
- 用户刷新后进入新版等待新观测状态；明确恢复观测后恢复正常显示。

## 检查

Codex 内置浏览器已核对上述状态，无运行错误；只有原型正常使用的 Babel 浏览器编译提示。断线重连前后年龄从约 89 秒增长至 109 秒，旧告警没有变新鲜。新版提示与旧告警同时保留；刷新后旧告警清空，等待新版观测。
