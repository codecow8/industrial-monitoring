# 01：服务器遥测协议与数据底座

Status: resolved

## 实现

- WebSocket 每键观测包含实际数据库 ID、值、服务器接收时间和来源时间；新增服务器时间基准、页面及发布版本。
- Agent 活动查询和 WS 快照共用最新观测读取及来源序列化，仅限当前版本发布之后、24 小时范围。
- 注册订阅后加载数据库快照，发送锁保证初始 snapshot 与 update 的顺序，不依赖易失内存缓存。
- 发布成功后旧订阅失效，通知版本变化并关闭旧连接；带旧版本的重连收到相同变化事件，不进入新版本资料。
- 智能分析过期标记改为共用的 5 秒标准，没有增加模型调用或设备操作权限。
- 更新 Data Freshness / Telemetry Snapshot 术语，协议说明见 `docs/telemetry-protocol.md`。

## 验证

- API 全套 29 项通过，含重连新 Hub 的原时间、逐键时间、发布隔离、智能分析 5 秒一致性。
- 后续新增“发布一页不影响其他页”公共 WS 回归测试，WS 专项 4 项通过；未为了新增这一例重跑其他已通过测试。
- 模型由既有测试边界替身提供，不消耗真实模型额度。

## 边界

本切片当时尚未接入正式客户端；该工作已在原型获批后的 03 中完成。重启案例采用新 Hub 和现有数据库，不声称做过真实进程故障恢复或部署验证。
