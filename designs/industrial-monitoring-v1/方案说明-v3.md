# 工业智能监控与巡检平台：实时遥测原型 v3

## 目标

在发布版本隔离的基础上，验证运行态首次快照、增量遥测、数据新鲜度、告警、断线和自动重连状态。

## 用户

- 组态工程师：在编辑器中配置监控页面。
- 现场操作员：在运行态查看实时指标与设备状态。

## 本次设计范围

1. 编辑器主屏：组件栏、网格画布、属性面板、Schema 预览。
2. 一个可用组件：指标卡。
3. 属性修改：设备名称、指标标题、数据键、单位、小数位和告警阈值。
4. 原型交互：拖动指标卡、修改属性、复制 Schema、保存草稿、发布版本、切换运行态。
5. 运行态：读取最近一次发布的 Schema 快照，展示版本号并去掉编辑控件。
6. 未发布空态：页面还没有发布版本时，说明返回编辑器发布后才能显示。
7. 遥测演示：每秒按固定序列更新温度，稳定经过正常、告警和恢复。
8. 异常演示：暂停上报后进入数据过期；模拟断线后自动重连。

## 明确不做

- Vue 工程和真实组件实现
- 真实后端保存、数据库和发布接口
- 真实 WebSocket、HTTP 遥测入口和设备连接
- Electron 与小程序
- AI 诊断 Agent
- 文本、折线图、设备状态和告警列表组件

## 信息架构

```text
监控画面编辑器
├── 顶部栏：页面身份、草稿状态、已发布版本、运行态预览、发布、保存
├── 左侧组件栏：指标卡可用，其余能力锁定
├── 中央画布：页面布局与组件选中状态
├── 右侧属性栏：组件属性与 Schema 预览
└── 底部状态栏：画布尺寸、缩放和组件数量

运行态预览
├── 顶部栏：页面名称、发布版本号、数据连接状态、返回编辑器
├── 已发布：呈现发布快照，不出现编辑控件
└── 未发布：展示明确空态
```

## 发布状态模型

```text
没有发布版本
├── 保存草稿 → 仍未发布
└── 发布版本 → v1

已发布 v1
├── 修改/保存草稿 → 运行态仍为 v1
└── 再次发布 → v2
```

## 遥测状态模型

```text
连接中
→ 已连接 · 等待 Telemetry Snapshot
→ 数据新鲜 · 运行正常/温度告警

暂停上报 5 秒
→ 连接正常 · 数据已过期
→ 保留最后值但降低强调

模拟断线
→ 连接已断开
→ 正在重连：1秒 → 2秒 → 4秒
→ 重连成功并接收新快照
```

运行态中的“原型演示”控制条只用于评审，不进入生产界面。

## 视觉方向

工业工具式的克制设计：深石墨蓝画布、浅灰侧栏、青蓝交互色、绿色正常状态和琥珀色告警语义。强调精密网格、清楚层级和紧凑信息密度，避免赛博朋克、玻璃拟态和通用后台卡片堆叠。

## 后续开发时的验收条件

- 修改属性后，画布和草稿 Schema 同步更新。
- 保存草稿不会修改已经发布的运行态内容。
- 发布后生成递增版本，运行态展示对应版本号。
- 再次编辑但不发布时，运行态仍展示上一次发布内容。
- 首次连接时先显示等待数据，再显示第一份快照。
- 固定数值序列能够稳定触发正常、告警和恢复。
- 暂停 5 秒后保留最后值并显示数据过期。
- 模拟断线后展示重连状态，并能自动或立即恢复。
- 编辑态和运行态不各自维护组件协议。
- 未支持组件不会误导用户为已经可用。
