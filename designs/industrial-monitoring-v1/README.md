- Maintain only `industrial-editor.html`, `prototype.jsx`, and `方案说明.md`.
- Update these files in place for every UI review.
- Use Git history instead of duplicated numbered prototype files.

- Update `_d_meta.json` with `needs-review`, `approved`, or `changes-requested`.
