# 工业智能监控与巡检平台：设备状态组件原型

## 目标

在已发布的趋势图与组件右键菜单基础上，增加 `device-state` 组件，使现场操作员能区分设备的 Device State 和 Data Freshness。

## 数据合同

- 默认 Data Point：`pump1.operating_state`
- `0`：停止
- `1`：运行
- `2`：故障
- `3`：维护
- 其他数值：未知状态，并显示原始状态码

Device State 不由温度推断，也不等于 WebSocket 连接状态。

## 默认组件

```json
{
  "id": "device-state-pump-01",
  "type": "device-state",
  "position": { "x": 610, "y": 130 },
  "size": { "width": 300, "height": 180 },
  "props": {
    "deviceName": "1号冷却泵",
    "title": "设备运行状态",
    "dataKey": "pump1.operating_state"
  }
}
```

## 视觉状态

- 运行：绿色，`设备运行正常`
- 停止：灰蓝，`设备已停止运行`
- 故障：低饱和红，`检测到设备故障`
- 维护：琥珀，`设备处于维护模式`
- 未知：中性灰，`未识别的状态码`
- 等待：`-- / 等待设备状态`
- 过期：保留最后状态，降低强调，显示 `状态数据已过期 · Ns前`

## 编辑器

- 解锁左侧“设备状态”。
- 点击后添加一个默认组件；已存在时再次点击只选中。
- 属性面板只开放设备名称、组件标题和 `dataKey`。
- 继续支持拖动、缩放、右键删除和撤销。

## 原型评审路径

1. 在组件栏点击“设备状态”。
2. 修改设备名称、组件标题或 `dataKey`。
3. 发布并进入运行态。
4. 使用原型控制区切换运行、维护、故障、停止和未知。
5. 暂停上报 5 秒，查看状态数据过期。

## 明确不做

- 多个设备状态实例
- 自定义状态码、颜色和文案映射
- 设备启停或远程控制
- 故障诊断和告警确认
