# 工业智能监控与巡检平台：实时趋势原型 v4

## 目标

在指标卡和实时遥测闭环基础上，验证第二种组件 `trend-chart` 能够复用 PageSchema、编辑器、发布版本、Renderer 和页面级 WebSocket。

## 本次范围

- 左侧组件栏解锁“折线图”，点击添加一个默认趋势图。
- 趋势图可选中、拖动、缩放，并配置标题、`dataKey`、单位、小数位和告警阈值。
- 每秒取当秒最新值形成 Trend Sample，仅保留当前会话最近 60 秒。
- X 轴显示实际时间；Y 轴自动量程并强制包含告警阈值。
- 阈值使用琥珀色虚线，越界线段和点转为告警色。
- 等待数据显示空态；5 秒未更新显示过期；断流不复制旧值，恢复后保留曲线缺口。

## 默认组件

```json
{
  "id": "trend-pump-01",
  "type": "trend-chart",
  "position": { "x": 80, "y": 405 },
  "size": { "width": 720, "height": 300 },
  "props": {
    "title": "1号冷却泵出口温度趋势",
    "dataKey": "pump1.outlet_temp",
    "unit": "°C",
    "precision": 1,
    "alarmThreshold": 80
  }
}
```

PageSchema 继续使用 `version: "1.0.0"`，纯指标卡的旧页面仍然合法。

## 明确不做

- PostgreSQL 遥测历史与时间范围查询
- 多 `dataKey` 曲线、图例和多 Y 轴
- 颜色、线宽和曲线类型配置
- 趋势图复制、删除与多实例管理
- Electron、小程序和 AI 诊断

## 原型评审路径

1. 点击左侧“折线图”。
2. 选中趋势图，修改图表标题或告警阈值。
3. 拖动图表头部，或拖动右下角控制点缩放。
4. 发布版本并进入运行态。
5. 观察每秒新增的 Trend Sample，使用“触发告警”查看阈值越界。
6. 暂停上报 5 秒查看数据过期，恢复后查看断流缺口。
