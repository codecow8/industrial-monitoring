# 产品操作指南

本指南面向配置监控页面的组态工程师。示例场景是配置一张冷却泵监控页面，展示出口温度、温度趋势和设备状态，保存并发布后交给操作员查看。

示例设备和数据来自项目模拟器，用于练习操作。它不代表已经接入真实工业设备，也不证明现场设备的运行情况。

## 开始使用

1. 确认 Web 页面、业务服务和数据库已由开发人员启动。
2. 打开编辑器。默认本地演示入口为 `http://127.0.0.1:5173/editor/demo`；其他环境以实际部署入口为准。
3. 等待草稿加载完成。出现加载失败提示时，先确认业务服务可用，再重新打开页面，不把失败当作空白草稿。
4. 使用左侧“组件”面板选择组件，在中间画布查看布局，在右侧“属性配置”修改选中组件。

查看变化中的温度和设备状态，还需要模拟器持续发送数据。仅成功打开页面不代表已经收到设备数据。

## 添加组件

### 使用已有指标卡

演示页面首次加载、且没有已保存草稿时，会预置温度指标卡。点击画布中的指标卡，在右侧修改设备名称、指标标题、数据键、单位、小数位和告警阈值。

当前左侧“指标卡”入口没有新增指标卡的操作。不要把点击该入口描述为会添加第二张指标卡。若已有指标卡被删除，本指南没有提供通过该入口重新添加它的步骤。

### 添加折线图、设备状态或告警列表

1. 点击左侧“折线图”“设备状态”或“告警列表”。
2. 对应组件出现在画布上，并成为选中组件。
3. 在右侧“属性配置”调整标题和该组件支持的属性。
4. 拖动画布中的选中组件调整位置，通过选中框调整尺寸。
5. 修改后保存草稿；需要让运行态看到修改时，再发布版本。

这三类组件当前各只能添加一个。再次点击已存在的组件类型，会选中原组件，不会新增第二个。

告警列表没有单独的数据键输入框。它汇总当前页面指标卡、折线图和设备状态所形成的活动告警；修改告警列表标题不会改变告警条件。

### 添加文本块

1. 点击左侧“文本”。
2. 在右侧填写“文本内容”，例如“冷却系统运行概览”。
3. 设置字号、文字颜色和对齐方式。字号范围为 12–64，对齐支持左对齐、居中和右对齐。
4. 调整位置和尺寸，然后保存并按需发布。

文本块可以添加多个，只展示纯文本，不绑定设备数据，也不解析 HTML 或 Markdown。

### 删除组件

在画布组件上点击鼠标右键，选择“删除”。删除会修改草稿；发布前，不会改变当前运行态使用的已发布页面。

## 绑定数据

“数据键”指定组件读取哪一项设备测量值或设备状态。显示名称只影响文案，不会替代数据键。

### 显示冷却泵出口温度

1. 点击画布中的温度指标卡或折线图。
2. 在右侧“属性配置”的“数据键”中填入 `pump1.outlet_temp`，与项目模拟器提供的出口温度对应。
3. 设置标题，例如“1号冷却泵出口温度”；单位可设为 `°C`，小数位可设为 `1`。
4. 使用演示配置时，将告警阈值设为 `80`。这是示例参数，不是通用设备安全阈值。
5. 保存草稿、发布版本，再打开运行态。模拟器正常推送该数据键时，组件才能显示更新的数据。

### 显示设备状态

1. 点击左侧“设备状态”添加或选中组件。
2. 将“数据键”设为 `pump1.operating_state`，设备名称可设为“1号冷却泵”。
3. 保存并发布后，在运行态查看状态。

当前状态映射为：`0` 表示停止，`1` 表示运行，`2` 表示故障，`3` 表示维护。其他数值显示未知状态并保留状态码；尚未收到值时，显示等待设备状态。

### 没有数据时怎样检查

- 确认填写的数据键与实际提供的数据键一致。填写不存在的数据键不会创建新的设备数据。
- 确认修改已发布，运行态不是仍在使用旧版本。
- 确认模拟器或数据提供方正在发送对应数据。
- 区分连接状态与数据新鲜度：连接存在不代表每项数据都持续更新。过期数据不能当作当前实时观测。

这些步骤只指导用户检查条件。第一版产品使用问答助手不会读取当前遥测、验证设备状态或查询告警证据。

## 保存草稿与发布版本

### 保存草稿

1. 完成属性修改或布局调整。
2. 点击编辑器顶部“保存草稿”。
3. 等待出现“草稿已保存”提示。

保存成功后，草稿可在再次打开编辑器时读取。保存草稿不会创建发布版本，也不会让运行态自动展示草稿修改。

修改属性和布局后，应主动保存，不要仅凭顶部状态文案认定修改已经保存到服务端。如果出现保存失败提示，不能把本次修改视为已经保存；检查服务状态后重试。

### 发布版本

1. 确认当前页面内容和数据键符合预期。
2. 点击顶部“发布版本”。该操作先保存当前草稿，再请求创建发布版本。
3. 等待出现“已发布 v…”提示，确认发布成功。
4. 点击“预览运行态”查看结果。若运行态已在其他标签页打开，刷新该标签页以重新加载最新发布版本。

发布版本是运行态读取的页面配置。发布之前的草稿修改不会替换旧版本。运行态在打开时加载发布版本，不会因为另一处完成发布而自动切换页面配置。

保存失败时，发布流程不会继续。发布失败时，即使草稿已经保存，也不能认定运行态已经更新；检查服务状态后重新发布。

### 预览运行态与发布的区别

点击“预览运行态”会先保存当前草稿，保存成功后进入运行态，但不会自动发布。

- 已有发布版本：预览显示已发布页面，可能与刚保存的草稿不同。
- 从未发布：预览显示“页面尚未发布”，需要返回编辑器执行发布。
- 草稿保存失败：不会继续跳转到运行态。

要查看最新修改，请先发布成功，再打开或刷新运行态。

## 查看运行态

1. 在编辑器中完成发布，并看到发布成功提示。
2. 点击顶部“预览运行态”。本地演示页面也可通过 `http://127.0.0.1:5173/runtime/demo` 打开；其他页面使用对应页面的运行态入口。
3. 查看顶部“发布版本 · v…”信息，确认正在查看已发布页面。
4. 查看温度、趋势、设备状态等组件。布局来自发布版本，实时数据来自对应的数据提供方。
5. 需要继续修改时，点击“返回编辑器”。完成修改后重新保存、发布，再查看运行态。

运行态不显示编辑器的选中框、拖动手柄或属性配置面板。

### 页面尚未发布

出现“页面尚未发布”时，点击“返回编辑器”，保存草稿并点击“发布版本”。发布成功后再次打开运行态。

加载发布版本失败属于服务请求失败，不能当作“尚未发布”。根据错误提示检查业务服务后重试。

### 运行态仍显示旧内容

先确认是否只保存了草稿；如果是，返回编辑器发布。已发布成功但旧运行态标签页没有变化时，刷新该标签页，重新加载最新版本。

### 组件已出现，但数据在等待或过期

页面发布只决定组件及其配置，不会启动模拟器或生成设备测量值。按“绑定数据”的检查步骤核对数据键和数据提供方，不把等待或过期状态推断为设备故障。

## 能力边界

以下定义第一版产品使用问答助手应具备的能力，不表示问答侧栏已经上线。

- 助手解释本指南覆盖的操作，提供步骤并引用对应章节。
- 用户请求“帮我直接发布”“替我修改阈值”时，助手说明只能提供指导，再给出人工操作步骤，不能声称已经执行。
- 第一版不查询当前告警、告警历史、实时遥测或设备状态。此类请求应说明能力范围，不能猜测业务数据。
- 当前会话中的追问可以延续操作话题；刷新后清空会话，不承诺跨会话记忆。
- 指南没有说明的功能、部署方式或权限，应明确表示没有足够资料，必要时请用户说明场景；不能编造入口、功能或权限。
- 示例数据键、阈值和状态码用于项目演示，不代表真实设备的通用接入规范或运行标准。
